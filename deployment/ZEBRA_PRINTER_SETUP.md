# Zebra Printer Setup Guide

## Quick Setup for Users

### 1. Install Zebra Browser Print
1. **Download**: Go to https://www.zebra.com/us/en/support-downloads/printer-software/browser-print.html
2. **Install**: Run the downloaded installer
3. **Connect**: Plug in your Zebra printer via USB
4. **Configure**: The software will automatically detect your printer

### 2. Use in the Application
1. **Open** the barcode management page
2. **Select** your printer from the dropdown (Zebra printers show with 🖨️ icon)
3. **Print** barcodes directly to your USB printer

## Features
- ✅ **Simple dropdown** with all available printers
- ✅ **Automatic detection** of Zebra and server printers
- ✅ **Zebra printers prioritized** (shown first in list)
- ✅ **Visual indicators** (🖨️ for Zebra, 🖥️ for server printers)
- ✅ **No complex configuration** needed

## Troubleshooting
- **Printer not showing?** Make sure Zebra Browser Print is installed and running
- **Print fails?** Check that your printer is connected and has paper
- **Need help?** Contact your system administrator

That's it! The system automatically handles everything else.
